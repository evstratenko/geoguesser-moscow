# Геогессер по Москве (на двоих)

Мини-игра: один экран показывает панораму Яндекс.Карт где-то в Москве, оба
игрока ставят точку на карте, где думают, что это — и получают очки за
точность. 5 раундов, побеждает тот, у кого больше суммарный счёт.

## 1. Получите ключ API Яндекс.Карт (бесплатно)

1. Зайдите на https://developer.tech.yandex.ru/services/
2. Войдите под своим Яндекс-аккаунтом.
3. Подключите **"JavaScript API и HTTP Геокодер"**.
4. Заполните форму (для личного проекта подойдёт любое описание, тип —
   "Некоммерческое использование").
5. Получите ключ — это строка вида `12345678-abcd-1234-abcd-1234567890ab`.
6. Откройте `public/index.html` и замените `YOUR_API_KEY_HERE` на этот ключ:

   ```html
   <script src="https://api-maps.yandex.ru/2.1/?apikey=ВАШ_КЛЮЧ&lang=ru_RU"></script>
   ```

Без ключа панорамы и карты не загрузятся.

## 2. Проверьте локально (по желанию)

```bash
npm install
npm start
```

Откройте `http://localhost:3000` в двух вкладках браузера — можно
протренироваться на себе перед игрой с другом.

## 3. Деплой на Render (бесплатно)

1. Создайте репозиторий на GitHub и залейте туда содержимое этой папки
   (включая уже вставленный ключ API в `index.html`).
2. Зайдите на https://render.com → New → Web Service → подключите репозиторий.
3. Настройки:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - Environment: Node
4. Нажмите Deploy. Через пару минут Render выдаст ссылку вида
   `https://ваша-игра.onrender.com`.
5. Отправьте эту ссылку другу — заходите оба и играйте.

> Бесплатный план Render "засыпает" после ~15 минут бездействия — первая
> загрузка после паузы может занять 30–60 секунд. Для разовых игр это не
> проблема.

## Как играть

1. Один из вас открывает сайт, вводит имя и нажимает **"Создать комнату"** —
   получает 4-значный код.
2. Второй игрок вводит тот же код и своё имя, нажимает **"Присоединиться"**.
3. Хост нажимает **"Начать игру"**.
4. В каждом раунде: смотрите панораму (можно вращать и приближать), кликаете
   по мини-карте, где думаете находитесь, жмёте **"Отправить догадку"**.
5. Когда оба отправили догадку — показывается результат раунда с расстоянием
   и очками. Через несколько секунд стартует следующий раунд.
6. После 5 раундов — итоговый экран с победителем.

## Настройка

В `server.js`:
- `ROUNDS_PER_GAME` — число раундов (по умолчанию 5).
- `MOSCOW_SPOTS` — список точек, из которых выбираются раунды; можно
  добавить свои любимые места Москвы (координаты `lat`/`lon`).
- `SCORE_DECAY_METERS` — насколько быстро падают очки с расстоянием ошибки.

## Как это устроено технически

- **Backend:** Node.js + Express (раздаёт статику) + Socket.io (комнаты,
  синхронизация раундов, подсчёт очков — всё в памяти процесса, без базы
  данных).
- **Frontend:** обычный HTML/CSS/JS, карты и панорамы — через Яндекс.Карты
  JavaScript API 2.1 (`ymaps.panorama.Player` для панорам, `ymaps.Map` для
  карты догадок).
- Игра рассчитана строго на 2 игроков в комнате; при выходе одного из них
  комната закрывается и второму нужно будет создать/зайти заново.
